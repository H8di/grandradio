# GrandRadio Website v14 — Full Archive via GitHub Actions

این نسخه مشکل «فقط ۱۰ آیتم» را از ریشه حل می‌کند.

## چرا نسخه‌های قبلی فقط ۱۰ آیتم می‌دادند؟
مرورگر برای خواندن RSS شنوتو با محدودیت CORS روبه‌رو می‌شود. fallback ما `rss2json` بود و نسخه بدون API key آن به صورت پیش‌فرض فقط ۱۰ آیتم برمی‌گرداند.

## v14 چه کار می‌کند؟
RSS دیگر داخل مرورگر دانلود نمی‌شود.

GitHub Actions:
1. آدرس کامل RSS شنوتو را می‌خواند.
2. تمام آیتم‌های Feed را استخراج می‌کند.
3. فایل `data/feeds.json` را می‌سازد.
4. آن را داخل Repository commit می‌کند.
5. سایت فقط فایل JSON خود Repository را می‌خواند.

بنابراین:
- CORS نداریم.
- محدودیت ۱۰ آیتم نداریم.
- MP3ها همچنان روی شنوتو هستند و روی GitHub آپلود نمی‌شوند.
- آرشیو ۹تایی + «نمایش آثار بیشتر» حفظ شده.
- ظاهر، Player و حلقه گرامافونی دست‌نخورده‌اند.

## نکته مهم درباره تست روی Mac
اگر `index.html` را با `file://` دوبار کلیک کنید، آرشیو کامل نمایش داده نمی‌شود؛ چون `data/feeds.json` باید ابتدا توسط GitHub Actions ساخته شود و fetch فایل محلی هم در بسیاری از مرورگرها محدود است.

نسخه v14 را روی GitHub آپلود کنید، سپس:
`GitHub → Actions → Update Shenoto archive → Run workflow`

بعد از پایان workflow، `data/feeds.json` با کل آرشیو ساخته می‌شود.
